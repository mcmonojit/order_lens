Creating AWS Access Key & Secret Key

Step 1 — Create an IAM User (recommended over root keys)

1. Go to AWS Console → IAM → Users
2. Click "Create user"
3. Give it a name (e.g., order-lens-s3-user)
4. Click Next

Step 2 — Attach S3 Permissions

On the permissions screen, choose "Attach policies directly" and add:
- AmazonS3FullAccess — for full access to all buckets, or
- Create a custom policy scoped to only your bucket (more secure):

{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": ["s3:GetObject", "s3:PutObject", "s3:DeleteObject", "s3:ListBucket"],
      "Resource": [
        "arn:aws:s3:::YOUR_BUCKET_NAME",
        "arn:aws:s3:::YOUR_BUCKET_NAME/*"
      ]
    }
  ]
}

Step 3 — Generate the Access Key

1. Open the user you just created
2. Go to "Security credentials" tab
3. Under "Access keys", click "Create access key"
4. Choose "Application running outside AWS"
5. Click "Create access key"
6. Copy both the Access Key ID and Secret Access Key now — the secret is only shown once

Step 4 — Store them securely in your project

Create a .env file in your project root (make sure it's in .gitignore):

env
AWS_ACCESS_KEY_ID=AKIA...
AWS_SECRET_ACCESS_KEY=your_secret_key_here
AWS_DEFAULT_REGION=us-east-1
S3_BUCKET_NAME=your-bucket-name

Then load them in your code with:
from dotenv import load_dotenv
import os

load_dotenv()
aws_access_key = os.getenv("AWS_ACCESS_KEY_ID")
aws_secret_key = os.getenv("AWS_SECRET_ACCESS_KEY")

---

Security tips:
- Never commit keys to git (.gitignore your .env)
- Use the least-privilege policy scoped to your specific bucket
- Rotate keys periodically via IAM
